# Lost Text Finder

A computational philology and signal-processing pipeline that scans surviving Greco-Roman prose compilations ("cover-texts") for unattributed fragments of lost ancient literature.
## Detection Channels
1. **Lost Historian Channel:** Detects abrupt drops in vowel-hiatus rates paired with Jensen-Shannon Divergence spikes in connective particle distributions.
2. **Lost Periplus (Sea-Voyage Manual) Channel:** Isolates formulaic ancient navigator logs (harbors, headlands, sailing distances in stadia, and directional sequences).
3. **Lost Epic / Nostoi & Tragedy Channel:** Extracts binary Long/Short syllable waves to detect embedded hexameter and iambic verse rhythms inside prose narrative.
